## Sobre mim

Sou desenvolvedor front-end em São Paulo, em busca da primeira oportunidade profissional
(estágio ou júnior). Comecei pelos fundamentos — HTML5, CSS3 e JavaScript — construindo cada
projeto do zero para entender o que acontece por baixo do framework, e hoje aplico essa base
no desenvolvimento de interfaces com React e TypeScript.

- Trabalho com **componentização**, **tipagem estática** e **consumo de APIs REST**.
- Trato **acessibilidade (WCAG)** e **responsividade** como requisitos, não como extras.
- Tenho projetos próprios em **Python** para automação, o que me dá repertório para conversar sobre back-end.
- Documento cada repositório com um README explicando o problema, as decisões técnicas e como executar.
